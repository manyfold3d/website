This week we've added a way to let API clients easily write changed content back to the same file, and some speed and stability improvements!

## What's Changed
### ✨ New Features ✨
* Add API PUT endpoint for overwriting raw file content by [@Floppy](https://github.com/Floppy) in [#6971](https://github.com/manyfold3d/manyfold/pull/6971)
* Add write-back URL to file API requests by [@Floppy](https://github.com/Floppy) in [#6977](https://github.com/manyfold3d/manyfold/pull/6977)
### 🐛 Bug Fixes 🐛
* Fix incorrect preview file selection after archive extraction by [@Floppy](https://github.com/Floppy) in [#6976](https://github.com/manyfold3d/manyfold/pull/6976)
* Fix overly-aggressive file type validation check by [@Floppy](https://github.com/Floppy) in [#6978](https://github.com/manyfold3d/manyfold/pull/6978)
* Fix non-applied filters on creator/collection pages by [@Floppy](https://github.com/Floppy) in [#6990](https://github.com/manyfold3d/manyfold/pull/6990)
* Fix translation files and config by [@Floppy](https://github.com/Floppy) in [#7024](https://github.com/manyfold3d/manyfold/pull/7024)
### 🔋 Sustainability & Performance 🔋
* Change pagination engine to Pagy - should be faster by [@Floppy](https://github.com/Floppy) in [#6975](https://github.com/manyfold3d/manyfold/pull/6975)
### 🌍 Internationalization 🌏
* Translations updated: de by [@Floppy](https://github.com/Floppy) in [#6940](https://github.com/manyfold3d/manyfold/pull/6940)
* Translations updated: es by [@Floppy](https://github.com/Floppy) in [#6980](https://github.com/manyfold3d/manyfold/pull/6980)
### 🛠️ Other Improvements 🛠️
* Pin footer to viewport bottom on short pages by [@facorazza](https://github.com/facorazza) in [#6946](https://github.com/manyfold3d/manyfold/pull/6946)
* Combine filename and ID lookup for show/raw/raw_put methods by [@Floppy](https://github.com/Floppy) in [#6974](https://github.com/manyfold3d/manyfold/pull/6974)
* Tidy up translations by [@Floppy](https://github.com/Floppy) in [#7007](https://github.com/manyfold3d/manyfold/pull/7007)
* ignore unused pagination keys by [@Floppy](https://github.com/Floppy) in [#7008](https://github.com/manyfold3d/manyfold/pull/7008)
