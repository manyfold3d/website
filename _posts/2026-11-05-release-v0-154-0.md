This release adds a huge new feature: built-in slicing for STL files using [Kiri:Moto](https://grid.space)! It can slice for a huge range of FDM and SLA/resin printers, as well as CAM machines, laser cutters, and more. We've also got interactive FreeCAD rendering now, thanks to the latest release of [F3D](https://f3d.app).

To slice, just choose an STL file, choose "slice for printing" from the menu or sidebar, and once it loads, hit the "slice & save" button. It'll do the work, and save the appropriate file (e.g. gcode), which you can then send on to a configured printer or download separately. At present, you need edit permission on a model to slice it, as it creates a new file, but we'll expand that in time to allow slicing for users with fewer permissions, and maybe even logged-out users. More formats will be sliceable in future as well.

Obviously this only works on single files, so if you want to fill your build plate, download the models and slice locally as you usually would. This is just a convenience for simple print jobs.

NOTE: As with any slicer, make sure you configure your printer properly in Kiri:Moto before slicing - Manyfold doesn't know enough to check you've not done something dangerous!
