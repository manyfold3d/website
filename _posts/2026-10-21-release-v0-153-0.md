This release is mainly to update CA certificates due to the [eMudhra certificate compromise](https://emudhra.we-have-a-problem.com), but also comes with adjustable resolution for the model thumbnail renderer.

## What's Changed
### ✨ New Features ✨
* Add adjustable resolution for the F3D preview pictures by @Grecco-O in [#7237](https://github.com/manyfold3d/manyfold/pull/7237)
### 🔒 Security 🔒
* Set minimum certificate package version for Docker images by [@Floppy](https://github.com/Floppy) in [#7389](https://github.com/manyfold3d/manyfold/pull/7389)
### 🐛 Bug Fixes 🐛
* Only show edit content link if there's an available editor by [@Floppy](https://github.com/Floppy) in [#7387](https://github.com/manyfold3d/manyfold/pull/7387)
* Fix coverage upload step by [@Floppy](https://github.com/Floppy) in [#7388](https://github.com/manyfold3d/manyfold/pull/7388)
### 🌍 Internationalization 🌏
* Translations updated: de by [@Floppy](https://github.com/Floppy) in [#7364](https://github.com/manyfold3d/manyfold/pull/7364)
* Translations updated: es by [@Floppy](https://github.com/Floppy) in [#7357](https://github.com/manyfold3d/manyfold/pull/7357)
### 🛠️ Other Improvements 🛠️
* Improve test runners by [@Floppy](https://github.com/Floppy) in [#7386](https://github.com/manyfold3d/manyfold/pull/7386)
