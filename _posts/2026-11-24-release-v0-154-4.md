This release includes a number of fixes for communication between federated instances which affected a couple of recent releases.

## What's Changed
### 🐛 Bug Fixes 🐛
* Fix unused translation string error by [@Floppy](https://github.com/Floppy) in [#7632](https://github.com/manyfold3d/manyfold/pull/7632)
* Fix infinite loop on following actors on other Manyfold instances by [@Floppy](https://github.com/Floppy) in [#7674](https://github.com/manyfold3d/manyfold/pull/7674)
* Check federation setting in all ActivityPub serializers by [@Floppy](https://github.com/Floppy) in [#7675](https://github.com/manyfold3d/manyfold/pull/7675)
* Fix application actor profile URLs (via Fedipub update) by [@Floppy](https://github.com/Floppy) in [#7678](https://github.com/manyfold3d/manyfold/pull/7678)
