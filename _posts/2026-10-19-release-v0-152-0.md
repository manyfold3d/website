This release adds the first step towards some exciting new features, with file editing. To start with it's just simple plaintext files, but this puts in place the framework for much richer editing capabilities one day!

## What's Changed
### ✨ New Features ✨
* Add simple editing interface for plaintext files (txt, markdown, html, js) by [@Floppy](https://github.com/Floppy) in [#7349](https://github.com/manyfold3d/manyfold/pull/7349)
### 🐛 Bug Fixes 🐛
* F3D renderer fixes by [@Floppy](https://github.com/Floppy) in [#7343](https://github.com/manyfold3d/manyfold/pull/7343)
* Fix alternate links for activitypub actors by [@Floppy](https://github.com/Floppy) in [#7348](https://github.com/manyfold3d/manyfold/pull/7348)
### 🛠️ Other Improvements 🛠️
* Add rel alternate links to profile pages, linking to activitypub representations by [@Floppy](https://github.com/Floppy) in [#7347](https://github.com/manyfold3d/manyfold/pull/7347)
* Improved display for Markdown and plain text files by [@Floppy](https://github.com/Floppy) in [#7356](https://github.com/manyfold3d/manyfold/pull/7356)
* Update & fix devcontainer by @Grecco-O in [#7365](https://github.com/manyfold3d/manyfold/pull/7365)
