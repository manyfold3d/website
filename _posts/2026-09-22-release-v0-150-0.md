This release is all about security! We've been through a big list of security issues that have been identified and fixed them. We've also upgraded the security of ActivityPub federation with RFC9421 signing and verification. Hopefully though, you won't notice *any* of that, because it's all behind the scenes!

There's one visible thing if you have a recent Prusa printer; you should be able to now use it via the modern API - before, we only had support for the legacy API.

## What's Changed
### ✨ New Features ✨
* RFC9421 HTTP signature/verification via Fedipub by [@Floppy](https://github.com/Floppy) in [#7118](https://github.com/manyfold3d/manyfold/pull/7118)
* Print via new prusalink api by @samuel-sarmah in [#7157](https://github.com/manyfold3d/manyfold/pull/7157)
### 🔒 Security 🔒
* Prevent moderators from editing administrators' user settings (including setting password) by [@Floppy](https://github.com/Floppy) in [#7119](https://github.com/manyfold3d/manyfold/pull/7119)
* Correctly sanitize markdown to remove unsafe HTML output by [@Floppy](https://github.com/Floppy) in [#7120](https://github.com/manyfold3d/manyfold/pull/7120)
* Fix possible conversion of unauthorized files by [@Floppy](https://github.com/Floppy) in [#7121](https://github.com/manyfold3d/manyfold/pull/7121)
* Fix sending out of user invitations before group permissions check by [@Floppy](https://github.com/Floppy) in [#7122](https://github.com/manyfold3d/manyfold/pull/7122)
* Prevent moderators from managing administrator's OAuth applications/tokens by [@Floppy](https://github.com/Floppy) in [#7127](https://github.com/manyfold3d/manyfold/pull/7127)
* Apply complete sandboxing to files displayed in frames, including HTML by [@Floppy](https://github.com/Floppy) in [#7128](https://github.com/manyfold3d/manyfold/pull/7128)
* Fix OAuth privilege escalation by [@Floppy](https://github.com/Floppy) in [#7129](https://github.com/manyfold3d/manyfold/pull/7129)
* Require user authentication for new follow page by [@Floppy](https://github.com/Floppy) in [#7131](https://github.com/manyfold3d/manyfold/pull/7131)
* Add proper permission checks to all associations in form deserializers by [@Floppy](https://github.com/Floppy) in [#7150](https://github.com/manyfold3d/manyfold/pull/7150)
### 🐛 Bug Fixes 🐛
