This release adds a whole new interactive renderer! For a while we've been using [F3D](https://f3d.app) to create model thumbnails, but now we've added the full renderer as a mesh viewer. That means we've got full view support for a load of new files, most notably STEP! 

This new renderer looks really nice, but doesn't yet have the customisation controls we have for the old renderer, so for now we're just using it for files that the old one can't support. In time though, as we get those controls working, this will probably become the new default viewer.

You can also now see a complete list of what files are supported for what functions on your instance's about page, so take a look and see what you can do!
