This release is all bugfixes, including a few for security issues.

## What's Changed
### 🔒 Security 🔒
* Fix CSRF protection by [@Floppy](https://github.com/Floppy) in [#7534](https://github.com/manyfold3d/manyfold/pull/7534)
* Use public IDs instead of database IDs in all forms by [@Floppy](https://github.com/Floppy) in [#7536](https://github.com/manyfold3d/manyfold/pull/7536)
* Fix incorrect print permission check by [@Floppy](https://github.com/Floppy) in [#7589](https://github.com/manyfold3d/manyfold/pull/7589)
* Exclude fetching content from private URLs, mitigating potential SSRF exploits by [@Floppy](https://github.com/Floppy) in [#7590](https://github.com/manyfold3d/manyfold/pull/7590)
### 🐛 Bug Fixes 🐛
* Update Report database content for Fedipub rename by [@Floppy](https://github.com/Floppy) in [#7533](https://github.com/manyfold3d/manyfold/pull/7533)
* Only use settings layout for API keys if user is a mod or above by [@Floppy](https://github.com/Floppy) in [#7535](https://github.com/manyfold3d/manyfold/pull/7535)
* Fix kiri:moto when using RAILS_RELATIVE_URL_ROOT by [@Floppy](https://github.com/Floppy) in [#7565](https://github.com/manyfold3d/manyfold/pull/7565)
* Fix tour state update on non-domain-root installations by [@Floppy](https://github.com/Floppy) in [#7564](https://github.com/manyfold3d/manyfold/pull/7564)
* Fix tiny scroll area bug by [@Floppy](https://github.com/Floppy) in [#7566](https://github.com/manyfold3d/manyfold/pull/7566)
* Fix image set preview button by [@Floppy](https://github.com/Floppy) in [#7608](https://github.com/manyfold3d/manyfold/pull/7608)
### 🌍 Internationalization 🌏
* Translations updated: lt by [@Floppy](https://github.com/Floppy) in [#7537](https://github.com/manyfold3d/manyfold/pull/7537)
* Translations updated: es by [@Floppy](https://github.com/Floppy) in [#7527](https://github.com/manyfold3d/manyfold/pull/7527)
